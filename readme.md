# LuxeAudio — Premium E-Commerce Product Page Template

**LuxeAudio** is a conversion-optimized, responsive frontend product detail interface designed for modern e-commerce experiences. Built entirely with standard modern web languages, it simulates dynamic real-time shopping operations like image gallery shifts, color variation switching, and cart count notifications.

---

## 🛠️ Project Structure
The repository consists of the following foundational frontend source files:

*   **`index.html`**: Core semantic markup layout structuring the interactive media viewing box, options configuration engine blocks, purchase counters, and description tab containers.
*   **`style.css`**: Scalable styles built on clean modern CSS variables, premium type pairing scales, modular flex layouts, and graceful responsive breakpoint rules.
*   **`script.js`**: Drives context state engine loops, thumbnail swappers, variant price tracking mapping, purchase item updates, and tab selection visibility panels.

---

## ✨ Features Built-In

1. **Interactive Image Gallery Swapper**: Instantly switch out main product display images by clicking or hovering over standard thumbnail grid items.
2. **Dynamic Color Variant Matrix**: Pick between different stock configurations to immediately update label strings, image display paths, and retail price values dynamically.
3. **Reactive Purchase Quantity Tracker**: Features an optimized step-counter block that honors programmatic boundary parameters (`min="1"`, `max="10"`).
4. **Animated Shopping Bag Badge Notification**: Provides real-time feedback loops via standard CSS transforms that update active badge metrics instantly.
5. **Tabbed Specification Panels**: Transitions smoothly between long-form product details and technical asset summaries within a modular workspace layout.

---

## 🚀 How to Run Locally

Because this project is built entirely as a pure **frontend template application**, it does not require bundle installation hooks or server runtime setups.

1. Download or clone all three repository files (`index.html`, `style.css`, `script.js`).
2. Make sure they are saved **directly next to each other** inside the exact same folder structure.
3. Double-click **`index.html`** or select "Open with Browser" through any modern web browser application (Chrome, Safari, Edge, or Firefox).

---

## 🔒 Session Limitations
This system operates entirely as a **100% frontend implementation template**. Shopping bag data states and selected options live transiently inside browser memory. Refreshing the browser environment or closing the application tab will safely clear data values back to the default black option setup.
